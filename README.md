# Personal Mini Website

My personal mini portfolio-ish website. Its actual primary purpose is to be a playground for me to learn about web
libraries and frameworks. But it also functions as a mini portfolio website on the side, showing more information about
myself.

The website's currently made using [Vite](https://vite.dev), [React](https://react.dev), and
[TanStack Router](https://tanstack.com/router/latest).
